The generator is the Python package `dataset_v2/` at the repository root: `world.py` (schedules and amendments), `policy_text.py`, `faq.py` and `render.py` (corpus), `engine.py` (reference policy engine that derives every label), `builder.py`, `cases_a.py`, `cases_b.py`, `cases_c.py` and `assemble.py` (scenarios and enterprise state), `build.py`, `validate.py`, `measure_retrieval.py`, `write_docs.py`.
